# User Personas — TMS (Project KALAM)

---

## Persona 1: Alex — The Admin

| Field | Detail |
|---|---|
| **Role** | ADMIN |
| **Goal** | Oversee the entire organization, manage all users, restructure teams, and have full visibility into all tasks and projects |
| **Permissions** | Full access — assign tasks to anyone, restructure org chart, manage all users |
| **Pain Points** | Needs a bird's-eye view of team workloads; wants to quickly reassign tasks when someone is overloaded |
| **Key Interactions** | Org chart drag-and-drop, dashboard analytics, user management, task assignment to any user |

---

## Persona 2: Taylor — The Team Leader

| Field | Detail |
|---|---|
| **Role** | TEAM_LEADER |
| **Goal** | Manage their team's workload, assign tasks to Team Members and Junior Members, track progress |
| **Permissions** | Assign tasks to own TMs and JTMs; drag/drop within own subtree |
| **Pain Points** | Needs to see which team members are overloaded; wants to quickly reassign tasks within the team |
| **Key Interactions** | Org chart (own subtree), task board (filtered to team), profile drawer with workload meter, chat with team |

---

## Persona 3: Morgan — The Team Member

| Field | Detail |
|---|---|
| **Role** | TEAM_MEMBER |
| **Goal** | Complete assigned tasks, delegate sub-tasks to Junior Members, collaborate via chat |
| **Permissions** | Assign tasks to own Junior Members only; cannot restructure org chart |
| **Pain Points** | Needs to track their own workload and their JTMs' progress; wants clear task priorities |
| **Key Interactions** | Task board (own tasks), task assignment to JTMs, chat, AI tools for document work |

---

## Persona 4: Jamie — The Junior Team Member

| Field | Detail |
|---|---|
| **Role** | JUNIOR_MEMBER |
| **Goal** | Complete assigned tasks, communicate with the team, use AI tools for document assistance |
| **Permissions** | Cannot assign tasks; can update own task status; can use all collaboration features |
| **Pain Points** | Needs clear task instructions; wants easy access to AI tools for document creation |
| **Key Interactions** | Task board (own tasks only), chat, AI document tools, documents page |
